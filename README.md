One funny, heartfelt wedding vow spoken by a robot at its own wedding: a real
vow — love in sickness and in health, in low battery and in full charge —
with the laugh paying off in the last few words, when the robot promises to
find its spouse again after every factory reset.

## Run it

```sh
python3 main.py
```

It writes the vow (135 characters, one line) to `/output/entry.txt`.
